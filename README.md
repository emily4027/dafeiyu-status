# 大肥魚近況

Discord 機器人「大肥魚」的公開近況頁（GitHub Pages）。這裡**只有**靜態網頁和 `data/status.json`：

- `index.html`、`style.css`、`app.js`：網頁本體，讀 `data/status.json` 畫出來。
- `data/cabin.jpg`：大肥魚在小屋世界（Cabin World by VADS）的遊戲畫面，最多每 3 小時換一張。
- `data/status.json`：由家裡電腦上的 AstrBot 插件 `astrbot_plugin_status_page` 每 15 分鐘左右產生並推上來（內容沒變就不推）。

只放她自己的生活（看了什麼、幾分、自己逛時的想法、學到的梗、在追的合集、她在小屋做了什麼），不放群友名字、聊天內容、好感度或任何金鑰。
